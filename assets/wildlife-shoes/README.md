# Wildlife shoe artwork

Generated artwork for the "Wild Guardians" shoe series (Lv.2–Lv.5, three colourways each). `build_wildlife_assets.py` renders the PNG/SVG files in `wildlife-assets/` from the NFT shoe templates in `web/nft/img/`.

Species are used as design inspiration only; see [asset sources](../../docs/legal/asset-sources.md) for licensing notes.
