# Wild Guardians｜鞋款細節預覽

開啟 [preview.html](preview.html) 比較四款鞋。圖形直接取自本次修改的 ShoeHero／WildlifeShoePattern TSX，使用系列預覽樣式；這是静態 SVG 美術檢閱，不是 Android 實機截圖。互動後跟／鞋面／鞋底導覽需在 App 的 Gear 鞋款詳情或 Demo 觀看。

重建：在專案根目錄執行 `node output/shoe-design-review/render.cjs`，需已有 app/node_modules/typescript。腳本使用簡化元件環境，只適用美術預覽，不替代原生渲染驗收。

完整敘事、來源與待驗收項目見 [設計文件](../../docs/design/wild-guardian-shoes.md)。
