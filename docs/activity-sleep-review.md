# Activity 呈現改善與睡眠停用盤點

2026-09-20。本版 `FEATURES.sleep=false`；原決策為 App 先隱藏睡眠，並非已完成全系統刪除。此次補齊停止讀取及現行宣傳清理。

## Activity 已修改

- 期間總覽改為獨立不透明卡片，距離、次數、平均配速／速度與時間分層；日期切換與圖表／月曆按鈕分列，縮小螢幕不擠壓日期。
- 加入回目前期間、已選日期清除、結果筆數、篩選空結果清除操作；紀錄卡加入實際開始時間、模式色線及指標分隔。排序偏好與同步由舊到新規則維持。
- 修正模式／來源／狀態篩選後，總覽、圖表與月曆未一起更新的問題；選圖表區間只縮小清單，總覽範圍有可見說明。
- 修正年檢視的月份、全部檢視的年份篩選；平均配速僅使用距離與時間均有效的紀錄，缺时间顯示 —。
- 切換期間時忽略舊請求回應，遠端快取按錢包分區；1,000 筆查詢上限顯示部分結果提示，不把不完整資料稱作完整總計。

## 睡眠殘留與處理

| 分類 | 發現 | 本次處理 |
|---|---|---|
| App 前景 | dashboard 雖隱藏卡片仍讀睡眠，可能使只有步數權限的同步失敗 | 停用睡眠呼叫、忽略舊睡眠快取、不查今日睡眠 receipt；service 增加停用防線 |
| Android 背景 | HealthSyncWorker 仍讀睡眠，缺權限可能連步數快取也不寫 | worker 只讀步數；保留空 sleep 欄位以相容快取格式 |
| 權限 | app.json、App manifest、原生模組 manifest 仍宣告 READ_SLEEP | 移除三处來源；需重新建置／安裝 APK 才影響裝置 |
| 可見文案 | 新手指南、Demo 規則、健康資料錯誤、活動權限說明、裝備維持點、打卡空狀態 | 更新繁中／英文現行文案，診斷頁隱藏睡眠讀取按鈕 |
| 對外素材 | README、官網中英文、隱私政策、Store 文案與中文募資稿仍宣傳睡眠 | 更新來源；募資 v4 與預覽／講稿重建 |
| 歷史紀錄 | ActivityHistory 仍可顯示過去睡眠打卡 | 刻意保留，歷史 receipt 不能改成步數或刪除鏈上歷史 |
| 協議與伺服器 | backend claim schema／風險規則、DB sleep 欄位、Anchor TASK_SLEEP=2、IDL、canonical bytes、測試仍有睡眠 | 保留相容性；後端仍可能接受合法舊版睡眠申請，不能宣稱伺服器已停用 |
| 舊設計與研究 | BRD／SA／SD、遊戲維持規則、經濟模擬、過去 PG 工作列仍有睡眠與雙任務假設 | 加現況提示、保留歷史與參數依據；待另立全系統退役及參數遷移工作 |
| 舊圖片與版本 | 早期 dashboard 截圖、舊版 PPTX／封存文件可能含睡眠卡 | 歷史素材保留；英文參賽第 1 頁仍標 EARLY BUILD，須用新 APK 實录替換，不應裁圖冒充已重錄 |

## 仍需決策的規則影響

目前鏈上每 7 日維持週期：步數每日 +100、睡眠 +50；Lv5 需要 900 點／6 活躍日。App 停用睡眠後，只靠步數最多 700 點，無法達到 Lv5 維持門檻。既有 DEC-04 仍需重新定案（例如調整全體門檻或經驗證的替代來源），不可只改 UI 數字假裝已修正。此次沒有改動鏈上參數、資產、既有成就資格或後端協議。

若目標為永久移除全系統睡眠，下一個工作需包括後端拒絕新睡眠 claim、處理已簽且未過期 attestation、鏈上新規則版本與玩家遷移、維持點／XP／經濟模擬重算、舊資料保留及政策。歷史 receipt、帳戶布局與 canonical bytes 不應直接刪欄。

## 驗證範圍

App TypeScript 檢查通過；Activity 畫面／資料函式、Health Connect、dashboard、雙語與指南共 6 組、32 項回歸測試通過。Android 健康模組 Kotlin 編譯及 debug manifest 合併成功，已確認合併後不含 READ_SLEEP。i18n 測試仍有非失敗的 Animated act 警告。未部署官網或安裝新版 APK；實機視覺、字體放大及背景工作排程仍需驗收。
