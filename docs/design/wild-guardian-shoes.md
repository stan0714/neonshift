# 荒野守護：跑鞋、成長盲盒與系列設計

更新：2026-09-17。狀態：App 第一版已實作，實機美術驗收待完成。

## 產品方向

Level 1 保留普通「原點」。Level 2 起，每階結合一種瀕危動物，將辨識特徵融入鞋面與結構，搭配保育故事。等級只代表遊戲成長，不代表動物價值、瀕危程度或抽取稀有度。

| 等級 | 名稱 | 鞋子元素 | 保育主題 |
|---|---|---|---|
| 1 | 原點 | 原有石墨網布 | 普通起始裝備 |
| 2 | 森行・亞洲象 | 象耳輪廓後跟護片、象鼻曲線縫飾、皮膚褶線抽象紋理 | 棲地破碎與人象衝突 |
| 3 | 潮盾・玳瑁 | 重疊龜甲鞋面、鰭狀後跟、海流曲線 | 野生動物交易、混獲與海岸棲地 |
| 4 | 林焰・老虎 | 漸尖虎斑、鞋頭虎紋、森林光軌 | 盜獵、棲地與獵物保護 |
| 5 | 雪影・遠東豹 | 斷環玫瑰斑、冬毛淺色鞋頭、豹紋光點 | 溫帶森林、生態廊道與反盜獵 |

圖案是數位仿生設計，不表示使用皮毛、象牙或玳瑁材料。

## 成長盲盒與微差異

- 同階三種外觀：晨曦縫光（金色縫線）、暮色紋跡（紫色紋樣／虛線軌）、極光軌線（薄荷色紋樣／加粗光軌）。虎斑和豹斑另有小幅位置差異。
- 未解鎖的鞋款詳情顯示盒子；可以先讀物種故事與解鎖條件。清單／Demo 可展示基礎設計，不代表已取得個人款式。
- 達到等級時沿用升階揭曉流程（全螢幕拆盒 5.2 秒：封印蓄能→搖晃漏光→盒蓋掀起→動物剪影現身→鞋款展示；可立即揭曉，減少動態直接顯示結果），展示該錢包的細節款與保育故事。已達階玩家直接取得穩定外觀，不必重新領裝備。
- 「試拆盲盒（示意）」：未解鎖詳情與 Demo 圖鑑可播放同一段揭曉，但標示 DEMO、使用系列展示樣式且不改任何狀態；真正的細節款只在達階那次揭曉。
- 微差異不改 XP、倍率、領取資格、供給或資產價值；沒有付費重抽。
- 目前使用 `seriesId + wallet + level` 的固定雜湊分配。此分配可預測，不是安全隨機、不可操縱抽籤或稀有度證明；不宣稱精確抽中機率。換錢包可能不同，同錢包重裝／跨裝置保持一致。
- 藝廊以被觀看玩家的錢包計算，不能用觀看者錢包。未連線、教學與 Demo 使用基礎展示樣式。

## 系列擴充契約

來源：`app/src/config/shoeCollection.ts`。首版系列 ID：`wild-guardians-v1`。

未來加入聯名應新增系列 ID／版本，不覆寫既有 ID、分配算法或 variants 順序。完整系列需要：

1. 系列名稱、發行方、版本及合作授權素材。
2. 各階設計、物種或主題、款式目錄與多語介紹。
3. 解鎖／取得規則、玩家所持系列與切換 UI。
4. 每個款式的資產識別與 metadata；發行後保留歷史映射。
5. 若有捐款或保育合作，再新增可查核的受款方、計算方式與紀錄。

目前只有第一個系列。尚未實作系列切換、聯名發行或安全隨機開盒。

## App 外觀與鏈上紀念 NFT

這次變更為 App 外觀及介紹層；鏈上紀念 NFT 仍沿用既有 kind／URI。`tools/nft-assets/build.mjs` 與既有 `web/nft/` 是舊版紀念作品，未在此變更覆寫或部署。App 提供外觀與 NFT 分開的說明。

## NFT 編號

- 編號定義：同一 kind 的紀念 NFT 依鏈上 `CollectibleReceipt.claimed_at`（同秒以 asset 位址）排序的領取順序，第 n 位即 `No. n`。鞋階款不限量（鏈上 `claim_collectible` 無供給上限、每錢包每 kind 一枚），因此不補零、不顯示上限；限量只屬於活動款（`No. 012 / 200`）。App 以單一 `getProgramAccounts`（memcmp discriminator＋kind、dataSlice 40 bytes）現算，不依賴後端；任何人可用同樣方式重算驗證。
- 呈現：升階揭曉（未領取 → `No. ——`，提示到裝備領取後編號）、NFT 揭曉（領取後立即查）、跑鞋詳情「NFT 編號」列；示意模式為 `No. 0001` 並標示示意。
- 限制：編號目前只在 App 呈現與可重算，尚未寫入鏈上 metadata（共用 URI）；玩家數大時 `getProgramAccounts` 應改由後端索引提供（gallery_collectibles 已有 slot／signature，可同樣排序）。

要讓盲盒款式成為 NFT 的永久屬性，後續須建立每資產的 `series_id / edition / variant` 權威紀錄、不可重抽的分配流程與獨立 metadata URI。現行按 kind 共用 URI 無法表達每錢包不同款式；不能只改共用 JSON 假裝每個 NFT 都有獨立結果。發行新系列時再決定是否使用可驗證隨機來源。

### 閱讀與互動

1. 鞋款名稱、短主張與棲地建立第一印象。
2. 點「後跟／鞋面／鞋底」切換局部放大（同一個 ShoeHero SVG，非另製圖片），同時呈現對應設計標題與故事。放大圖保持靜止；按鈕至少 48dp、可換行，選取狀態與細節更新提供無障礙資訊。
3. 下方分開呈現「值得留下的家」物種內容、「下次出發，帶上這個念頭」情感短句與一個小行動。
4. 未解鎖及 Demo 僅使用系列預覽樣式，保留成長盲盒及外觀／NFT 區別說明。閱讀與切換細節不解鎖鞋款，也不分配個人款式。
