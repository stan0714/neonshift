# 運動三階段操作體驗（2026-09-22）

- 開始：目標卡縮短，開始鍵改為彈性寬度，降低小螢幕被大型圓形按鈕擠壓的問題；開始前說明選模式、目標與倒數順序。室內限制與權限提醒保留。
- 進行中：狀態列與控制列固定，警告、定位診斷與數據可捲動，避免多個警告把控制鍵推離畫面。固定提示先暫停再結束；暫停時說明繼續或保存。
- 結束：保存缺漏、待檢查、同步狀態與錯誤提到頁首；距離之後即可進入運動紀錄，不需滑過全部分析和分享設定。資料卡與同步列允許換行。
- 背景通知檢查由解鎖元件移回記錄頁：進頁及回前景即檢查，不必先鎖定；通知被停用時提供設定入口。

驗證：TypeScript 與運動畫面測試；仍需在 Android 實機檢查窄螢幕、大字體、GPS 警告同時出現及背景通知返回。未將此修改視為實機驗收完成。
