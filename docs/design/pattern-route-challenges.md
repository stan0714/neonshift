# 特殊圖案路線挑戰與 GPS 分享

2026-09-20｜新增開發規劃，全部 TODO；尚無 GPX 匯出、匯入或挑戰驗證功能。需求 FR-22.1～22.5，工作包 PG-ROUTE-01～07。承接 GPS 記錄、Activity 及固定 route 外觀。

## 1. 產品與交付範圍

讓使用者把實際走出／跑出的愛心、星形、動物輪廓等軌跡建立為可分享的挑戰，其他人收藏路線，日後到同一地點完成。圖案是 GPS 路徑形成的形狀，不是換一張 route 背景。

第一階段採「同地點沿線挑戰」：分享真實位置、路線與檢查點，接收者必須實際記錄一次新運動。第二階段才評估「異地仿畫圖案」：允許在其他城市重現形狀，使用獨立比對與分類，不和原地挑戰混算。首版不做速度競賽、代幣加成或自動 NFT 發放；完成可取得私人完成章與分享摘要。建立、匯出、匯入與挑戰不限鞋階，跑鞋只控制自己的外觀。

## 2. 使用流程與畫面

1. Activity → 有本機 GPS 點的已完成運動 →「建立路線挑戰」。只有遠端摘要者提示缺少路線，不能從距離／配速捏造座標。
2. 本機建立獨立草稿：名稱、圖案分類、適用跑步／健走／散步、起終點、距離、路面／爬升（缺值不估造）、預計耗時範圍（有依據才顯示）、通行說明、方向與檢查點。可裁掉敏感區段並另存模板，不改原運動或其已固定背景。
3. 預覽要分享的實際座標與圖案、起終點、匯出欄位；確認精確地點揭露後選「匯出 GPX」或後續「建立分享連結」。使用 OS 分享面板，由本人選對象；不自動發訊息。
4. 接收者用檔案／連結開啟 → 地圖與圖案預覽 → 顯示來源、版本、距離、方向、通行資訊與資料完整度 →「收藏，之後挑戰」。匯入檔只建立路線模板，絕不匯入成已完成運動、PB、XP 或任務證據。
5. 從「我的路線挑戰」進詳情 → 確認當地條件 →「開始挑戰」→ 既有 GPS session。運動前可選自己已解鎖的背景；邀請者的高階背景只作預覽，不授予接收者外觀權限。
6. 完成後顯示匹配路段、漏走檢查點、覆蓋率及品質不足原因；可重試。Activity 詳情增加模板名稱／版本、完成或待確認狀態；分享只輸出明確勾選資訊。

## 3. GPS 匯出／匯入（FR-22.1、22.2）

首版格式選 GPX 1.1，含 WGS84 座標、路線軌跡與可選 waypoint。GPX 的座標、track／segment／waypoint 結構依 [Topografix GPX 1.1 原始規格](https://www.topografix.com/gpx/1/1/)（2026-09-20 查閱）。以下欄位取捨為 NeonShift 設計，非標準強制要求。

- 匯出挑戰模板採 `trk/trkseg/trkpt`，檢查點採 `wpt`；保留分段，不跨 GPS 缺口畫直線補路。預設移除每點時間、心率、熱量、錢包、裝置識別及私人備註，保留完成路線所需經緯度。海拔僅來源可用且使用者同意時輸出。
- GPS 挑戰必然需要位置，不能宣稱「匿名 GPX 沒有位置資訊」。社群圖片預設仍不附 GPS 檔，兩種分享獨立確認。
- GPX 可用標準 extensions 放 template ID／版本、方向及檢查點規則；其他軟體可能忽略 extensions。普通 GPX 匯入則生成本機規則草稿，使用者確認後開始，不假稱已取得原作者官方挑戰。
- 校驗座標範圍、數值有限、點數、段數、XML 大小、空檔／重複點、順序與檔案內容。預設工程上限暫訂 5 MB／50,000 點，須在 Seeker 校準後定案；超限明確拒絕，不默默截斷形狀。簡化只用於預覽；正式匹配保留原模板或版本化精度。
- XML 禁用外部實體、DTD 與遠端資源解析；不執行 extension 內容或自動開啟內嵌 URL。只支援明確可解析的 GPX 子集，其餘顯示不支援原因。
- 檔案內容雜湊去重，匯出後再匯入須保留路段及檢查點語義；同名不同內容視為不同版本。GPX 對其他 App 的相容性需實測，不宣稱普遍支援。

## 4. 路線挑戰判定（FR-22.3）

模板需具體定義版本化規則：允許走廊寬度、最低有效路段覆蓋、GPS 品質、檢查點順序與容許半徑、正向／反向、起終點要求。參數不能在參加後改動；初版門檻先以已知路線校準，不在未測試前承諾辨識率。

- 依實際 GPS 點／連續段與模板有序路段匹配，累計「不同模板路段」的覆蓋，不以來回刷同一段增加完成度。
- 交叉／迴圈圖案需路段索引與檢查點次序，不能只以最近距離或抵達終點判完成。若允許反向，開始前確定方向；閉合路線起點可否平移必須由模板明訂。
- 缺口／低精度段不補直線、不靠總里程補足覆蓋；長暫停與恢復沿用既有 session。模擬定位、瞬移、超速與未完成路段沿用品質檢查，結果分 completed／incomplete／needs_review／interrupted。
- 首版比對在本機執行，顯示「裝置比對」，後端只收同意的匹配摘要，不稱為獨立驗證 GPS 真實性。原始挑戰者軌跡仍不上傳；獎金／公開競技驗證需另設信任與審查方案。
- 異地仿畫後續另案：平移／縮放／旋轉是否允許、鏡像、最短距離、拓樸／形狀分數、容差校準皆需明訂，不把位置相近算法直接套用。

## 5. 固定背景、模板版本與隱私（FR-22.4）

**原始運動、分享模板、挑戰嘗試是三種獨立資料。** 已保存運動的 `routeAppearance` 仍不可更改；裁切分享區段只產生新模板副本。挑戰開始綁 `templateId + revision + geometryHash + rulesVersion` 與挑戰者自己的 route 外觀快照。路線更正另建 revision，既有嘗試／成績保留舊版；安全下架可停止新挑戰，不暗改既有結果。

保留既有「原始 GPS 本機保存」預設：

- R1 本機 GPX 檔匯出即可分享，不上傳平台伺服器。分享後的外部副本不能遠端收回；刪除 App 紀錄不等於刪掉別人的檔案。
- R2 分享連結會上傳使用者明確選出的「可分享路線模板座標」，是新增且独立的同意範圍。必須先更新產品告知／隱私政策、儲存與刪除規則，不能沿用摘要同步的同意。
- 分享草稿預設私人，連結採不公開搜尋／可撤銷 token；持有連結者可轉傳，不能稱只有原收件者可見。有效期預設 30 天，到期停止平台下載；下載副本不受撤回控制。公開路線市集另期開發。
- 提供起终點敏感區域遮蔽／裁切預覽，但不保證剩餘路線無法推知住處。裁切影響圖案或必經路段時重新定義模板起終點、覆蓋分母與檢查點；不得把隱藏區段仍列為必走。若模板不連續或無法合理通行，禁止發布成挑戰，可僅匯出標示不完整的個人檔案。
- 危險道路、私人土地、保護區與季節封閉需提示／回報／下架；圖形好看不等於可安全通行。首版以人工核對公開步道的測試路線試辦，不產生鼓勵橫越封閉區域的捷徑。地圖授權、供應商及導航路網未完成前，不宣稱轉彎導航或道路安全認證。
