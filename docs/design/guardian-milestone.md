# 一起點亮荒野｜共同彩蛋與朋友邀請

更新：2026-09-19。使用者已確認：**某款鞋的全體領取數，超過對應物種的野外族群參考值**。本輪實作彩蛋與主動系統分享；個人邀請連結／短碼／朋友關係為下列後續建議，尚未實作。

## 1. 體驗

主張：「一個故事，有了更多同行的足跡。」／“One story. Many footsteps.”

- 未達標：鞋款故事顯示族群資料來源、估計語氣、資料年份（來源未註明就明說）、查核日、網路、領取數與剩餘筆數。
- 嚴格超過門檻後：卡片變為「這一次，我們一起看見了新的風景」，提供「走進一起點亮的棲地」。所有查看者均可進入，早期領取者不被排除。
- 場景：光點、連接棲地的線條、對應動物剪影淡入，搭配鞋款與共同敘事；減少動態模式直接靜態呈現。光點數量僅為設計意象，不逐一對應動物或真人。
- 參與者自主按「邀朋友，一起認識這個故事」，由系統分享面板選 LINE、訊息等目的地。沒有自動傳送。
- 不強制彈出／分享；關閉按鈕與系統返回均可用。NFT 領取後自動查數量，但須本人按入口才進全畫面；一般鞋款故事按需查詢，避免每次開啟四款圖鑑都掃鏈。
- Demo 使用門檻 + 1 的明示模擬資料；不查鏈、不修改領取數、不建立解鎖紀錄；分享文字不包含模擬達標數。

入口：Gear → 鞋款詳情 → ShoeStory → 共同里程碑；NFT 領取完成頁；歡迎頁 Demo → 鞋款故事 → 示意預覽。

## 2. 門檻來源與版本

固定版本的**教育參考值**，不是即時普查，也不能宣稱「領取數已超過今天全球真實存量」。來源更新時新增版本、重新審核，不暗中降低门檻刺激達標。

| 鞋款 | 來源表述／數值 | 本版達標條件 | 口徑 |
|---|---|---|---|
| 亞洲象 | 少於 50,000 | finalized 領取 > 50,000 | 採來源上界作門檻；來源未明確標示該估計的調查年 |
| 老虎 | 約 5,574 | finalized 領取 > 5,574 | GTF 2023 估計，由 WWF 引述；不是僅蘇門答臘虎或東北虎 |
| 遠東豹 | 約 130 | finalized 領取 > 130 | WWF UK 物種介紹頁，頁面最後審閱 2025-07-29；該數字的調查年未列明 |
| 玳瑁 | 未取得可比較的全球全體數量 | 暫不啟用數字彩蛋 | 不以產卵雌龜、巢數、區域統計代替全球總數；保留故事與分享 |

2026-09-19 查核來源：

- [WWF — Tackling Critical Threats Facing Asian Elephants](https://www.worldwildlife.org/news/stories/tackling-critical-threats-facing-asian-elephants/)

不同 WWF 頁面存在遠東豹 84 以上／約 120／約 130 等不同版本，不能把下限「至少 125」誤當完整族群估計。本功能明示採哪份資料，不假裝全球各來源一致。未來若有更新的跨境普查，另開參考版本。原鞋款故事不列族群數字的規範仍適用；此處是有來源、版本及限制標示的獨立比較模組。

## 3. 領取數口徑

本版資料由 `GuardianCountService` 查目前 build 的 program／cluster，使用 finalized 的 `CollectibleReceipt` discriminator 與鞋款 kind 過濾，回傳 total 和查詢完成時間。零長度 dataSlice 只取帳戶清單，無須下載持有人資料或連接錢包。

- 計算的是同 kind 歷史紀念 NFT 領取筆數，**含改版前相同 kind 的舊外觀**；不是「本系列上市後新增的真人數」、裝備外觀數或目前持有人數。
- 既有鏈上每錢包同 kind 一份 receipt；NFT 轉手不增加筆數。同人多錢包仍可能增加，故不稱獨立參與者。
- 每網路分開；devnet 不合併 mainnet。頁面與場景保留目前網路標籤。
- 使用 total，而非個人 edition；嚴格 `>`，例如 130 尚未開啟，131 才開啟。
- 失敗／非整數／負數／無參考值均不能達標；查詢失敗清除本次可用數字，不以 0 或假成功取代。
- 領取剛 confirmed、尚未 finalized 時可能稍晚計入，可手動更新。
- 本版是可重看的 UI 場景，未發獎、未新增 NFT、未記錄「誰是最後一位」；不必因多錢包刷量引入獎金誘因。

擴充建議：將大量 getProgramAccounts 改為 finalized indexer 的公開聚合 API，回傳 program／cluster／kind／total／asOfSlot／indexedAt；做缓存與異常回退。若要永久記錄首次跨越，後端以 network + program + kind + referenceVersion 的唯一鍵保存事件，再做使用者已看紀錄；目前未實作，不能宣稱永久里程碑憑證。

## 4. 朋友邀請：現在與下一階段

現在已有活動分享（活動網址＋source=invite）及本次鞋款故事分享（官網首頁＋通用邀請文字）。都**不等於可辨識邀請人的個人邀請、不自動加好友、沒有短碼兌換或安裝後續接**。本次没有發出任何實際邀請訊息。

### 建議使用體驗

1. 跑者按「邀朋友」，選鞋款故事／活動／未來小隊。
2. 系統分享一張簡短文案及不含錢包地址的邀請網址。
3. 朋友打開網頁，先看到故事、共同目標與邀請者選擇公開的暱稱。不先要求錢包或簽名。
4. 已安裝者開啟 App 的同一內容；未安裝者可先唯讀瀏覽，再取得可用安裝入口。
5. 安裝後重新開原連結，或輸入短碼；不要承諾系統一定自動保留安裝前目的地。
6. 只有接受小隊邀請、活動報名或領取收藏才完成必要登入；連錢包後顯示「以哪個帳號接受」，由本人確認。
7. 單純接受活動邀請不建立朋友關係；朋友關係另需双方同意。參加者可以只一起參與一次。

### 身分與程式設計建議（未實作）

| 層級 | 建議 |
|---|---|
| 對人顯示 | 可選暱稱、頭像與短識別碼；錢包地址留在帳號設定與驗證詳情；暱稱不當唯一鍵 |
| 社群身分 | 後端穩定 member_id；邀請、隊伍與偏好指向此 ID；現有 players.wallet 主鍵先保留，透過映射逐步遷移 |
| 錢包 | 作登入／資產驗證，不當公開邀請碼。多錢包連結需證明兩端控制權；禁止僅憑相同暱稱自動合併 |
| 分享網址 | 例如 `/i/<opaque-token>` 為未來路由，服務端儲存 token hash、目標與版本、期限、可用次數、撤銷狀態；本版不發布不存在的路由 |
| 輸入短碼 | 8–10 碼易辨識字元，配限流、過期、嘗試次數限制；只用來找到邀請，不當登入憑證 |
| 接受 | 需有效 session、明確同意、原子名額檢查、冪等 receipt；排除自己邀自己；換帳號後重確認 |
| 個資 | 預設不共享錢包全碼、步數、路線、精確日期、其他隊友數字；不讀通訊錄、不自動發送 |
| 信任 | 錢包簽名不代表真人唯一性；先做共同外觀／故事解鎖，不以邀請數發放可交易獎勵 |

### 開發順序

- **P1：** 公開邀請落地頁 → 有效期／撤銷／短碼 → App 內容續接 → 匿名瀏覽與按需登入。沿用 PG-XD-06 的生命週期，避免另造一套來源參數即好友的機制。
- **P2：** member_id 映射與暱稱 → 小隊接受 → 双方同意的朋友關係 → 帳號切換／錢包恢復。需另排 API、資料遷移與權限測試。
- 第一階段保留現有錢包登入；若未來評估 passkey／嵌入式錢包，先做獨立恢復與資產遷移設計，不與這次彩蛋綁成上線前置。
