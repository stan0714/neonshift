# 跑鞋升級連動與固定路線外觀

2026-09-20｜程式已修改，實機驗收待完成。取代舊版「在已保存摘要切換底圖／全部歷史跟隨目前跑鞋」行為。

## 本次優化

| 區域 | 原行為／問題 | 新行為 |
|---|---|---|
| 運動開始頁跑鞋 | 使用最高鞋階，可能與實際選用外觀不一致 | 顯示目前選用跑鞋，與背景選擇及鞋款快照一致 |
| 運動前設定 | 底圖只能在運動完成後切換，影響所有歷史 | 開始前選擇，提供預覽、跟隨跑鞋、四款基本底圖及棲地解鎖狀態 |
| 升級連動 | 目前外觀會回溯套到舊路線 | 升級或選鞋只影響下一場；已有明確選擇不強制換成新鞋 |
| 記錄中／恢復 | 從全域偏好重算底圖 | 讀取本次開始時的快照；換設定、換鞋或崩潰恢復不換底圖 |
| 摘要 | 存檔後還能換底圖 | 移除編輯器，顯示「已保存背景／已固定」；路線顯示開關只控制可見性 |
| Activity | 所有縮圖使用現在的鞋與偏好 | 每筆使用自己的路線快照；遠端詳情顯示保存的背景名稱，無 GPS 不偽造路線 |
| 本機與伺服器 | 更新 metadata／source revision 可蓋掉底圖 | 儲存層保留第一次背景，更新成績、同步 ID 或重試不能改寫 |

棲地依既有階級：Lv1 格線、Lv2 森林、Lv3 海洋、Lv4 密林、Lv5 雪林。棲地選擇沿用曾取得鞋階資格，不影響 Active level、倍率或 PB 資格；頁面背景關閉不改路線畫布設定。

## 固定資料與相容性

- `SessionMeta.routeAppearance = { version: 1, layer }`，開始運動時解析 `shoe` 為具體 layer；不保存會隨玩家改變的 `shoe` 指令。
- 本機每次寫 metadata 都保留磁碟既有快照，包括摘要保存、恢復及同步結果寫回。快照與紀錄同一次原子寫入。
- 上傳至 `extras.route_appearance`；MemoryStore 與 PostgreSQL upsert 在新 source revision 保留原快照，PostgreSQL 在既有玩家鎖／row lock 內決定，不能靠更正數值更換外觀。
- 舊紀錄缺快照時固定 grid v1，不能還原過去曾看過的背景，也不按目前跑鞋猜測。首次後續写入補相同 fallback，遠端舊紀錄更正也不能改成新棲地。
- 未知／格式不合法快照安全回到 grid v1。這是 App 保存規則，不是鏈上防竄改證明；首次上傳的外觀不是 NFT 權利或成績認證。
- version 1 的圖層 ID／美術內容應保留；未來變更畫法需新增版本並保留舊渲染器。現在鎖定的是背景種類與版本，縮圖和詳情尺寸不同，不承諾兩者逐像素一致。

|---|---|---|

| 每雙鞋的運動里程／次數 | 優先：在我的跑鞋顯示真實使用歷程，增加切鞋意義 | **已實作（2026-09-20，Style 23.20）**：`shoeMileage` 依 session.shoeSnapshot 歸組（本機紀錄、只算該玩家）；待審／刪除中另標「n 筆待審」；沒穿過顯示提示；不增加 XP 或獎勵 |
| 升階後首次運動紀念 | 可納入：首次穿新鞋完成運動後顯示一次小型紀念卡 | **已實作（2026-09-20，Style 23.21）**：摘要頁 `isFirstWear`——同玩家＋同 shoeId 中最早的 saved 場次（待審／刪除中／訪客／Lv.1 不算）顯示紀念卡，關閉記在該紀錄 `firstWearDismissed`；不鑄 NFT、不加 XP、不在運動中彈窗 |
| 棲地故事與路線圖例 | 可納入：完成頁可選讀物種故事、解釋目前棲地，搭配靜態圖例 | 純展示，使用已查核故事來源；不宣稱運動等於實際保育成果 |
| 配色／完成儀式 | 後續：鞋款色調可用於紀念卡邊框及完成動畫 | 保留運動模式色、GPS 警示色及可讀性；Reduce Motion 靜態，不能全介面換色造成狀態混淆 |
| 付費重抽／速度倍率／額外代幣 | 不納入此視覺改版 | 外觀不影響成績、GPS 品質或成就資格 |

社群分享需逐次預覽／確認；預設只含摘要與抽象背景，不含原始路線、精確位置或錢包。未來若提供路線分享，需明確同意與起終點隱藏；背景固定不能取代位置保護。隱私欄位的隱藏／刪除與「更換原紀錄背景」分開處理。

本次沒有新增社群 SDK、自動發布或 PNG 分享功能；既有文字分享維持。新候選需完成資料與實機驗收後再標為可用。

## 驗證

App 與 backend TypeScript 通過；App 7 組共 60 項測試、後端 workout API 11 項測試通過（MemoryStore）。PostgreSQL 使用同一固定外觀函式並在既有交易鎖內呼叫，尚未執行真實資料庫整合測試。App 動畫測試有既有 act 警告，不影響測試結果。尚未部署或實機驗收。
