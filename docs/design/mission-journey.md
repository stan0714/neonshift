# 任務挑戰路線

2026-09-21｜首頁新增任務導覽與 XP 回饋。

- 今日顯示「已領取 / 可執行任務數」，區分進行中、已達標待打卡、已領取；完成兩項後引導探索里程或等待 UTC 換日。
- 說明步數 8,000，以及單次 GPS 跑步／健走至少 1 km、移動 10 分鐘、同步且審核通過。兩項各每日一次，不把多場短運動任意合併。
- 每張任務卡顯示確認後 XP 與進度條，保留代幣估算、待同步／待審及阻擋原因。GPS 進度條使用可採認距離，未審核不假裝已達標。
- 下一雙跑鞋使用載入的鏈上 shoeXpThresholds 與玩家 XP，顯示剩餘 XP，向上取整換算 100 XP 任務領取次數。不換算成保證升級天數；維持規則與現役鞋階仍適用。
- 展開後可查看跑鞋獎勵／維持規則，或前往運動紀錄頁探索首次 5 km、10 km、半馬、全馬等成就資格。這是成就路線預告，不是宣稱使用者已符合鑄造資格。
- 缺少帳戶／規則時顯示載入提示，不使用設計預設門檻冒充個人目標。滿階改為維持與里程挑戰。
- 未新增 XP、代幣、成就門檻或額外付費機制；每日 XP 取自既有 SHOE_PROGRESSION，steps/workout 100 XP 對應鏈上常數。
- 測試涵蓋自訂鏈上門檻、任務領取數、導覽與缺資料；真機窄螢幕、字體放大與長文閱讀待驗收。
