# SKR 質押加成與保育提撥（Roadmap，未實作）

建立：2026-10-06｜狀態：**規劃，未實作、未部署**｜對應 PG-EC-06｜參賽投影片第 10 頁（[FlexClip v4](../../output/hackathon-flexclip-en/flexclip-v4/README.md)）

## 構想

1. **質押加成**：玩家可質押 SKR，提升每日任務獎勵（加成作用在任務獎勵上）；跑鞋等級越高，同樣的質押取得的加成比率越高。
2. **保育提撥**：加成所產生的額外獎勵中，固定比例撥入獨立追蹤的野生動物保育基金；撥款與使用另行公開對帳。

## 示意參數（未定案）

| 跑鞋等級 | 質押加成（疊加在既有等級倍率之上） |
|---|---|
| Lv.1 原點 | +1% |
| Lv.2 | +3% |
| Lv.3 | +5% |
| Lv.4 | +7% |
| Lv.5 | +10% |

保育提撥：加成獎勵的 10%。

以上數字只用於投影片示意，**不是承諾**；正式比率須依 [經濟風險評估](../economics/stepn-risk-review.md) 與 PG-EC-02～05（成長與獎勵拆分、全站預算、對帳與準備金、反作弊）完成後的試算決定。

## 對外說明界線

- 目前只有 devnet 與無金錢價值的 tSKR；官方 SKR 與主網尚未啟用（DEC-02）。
- 不承諾收益、報酬率或價格；加成作用在 App 任務獎勵，不是投資回報。
- 保育提撥是規劃；未宣稱已有合作對象或已完成捐款。物種資料引用 WWF 不代表合作。
- 加成不能購買 XP、成績或成就；跑鞋等級仍只靠運動取得。

## 上線前需決定

- 質押鎖定期、解鎖等待、提前解鎖規則；作弊判定時的處置。
- 加成上限與全站預算的關係（避免加成使金庫提早耗盡）。
- 保育基金的收款方、撥款頻率、公開帳本格式與第三方查核。
- 法規與主辦方規則審查（真實代幣質押）。
