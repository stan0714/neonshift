專案概述：NeonShift (賽博躍遷)NeonShift 是一款專為 Solana Mobile 打造的「賽博融合 (Cyber-Fusion)」健康追蹤 App。我們將枯燥的日常運動轉化為賽博特工在虛擬網路中的「打卡 (Clock In)」任務。透過無縫整合手機硬體健康數據與 Solana 區塊鏈的低延遲特性，NeonShift 讓使用者的每一步都成為驅動數位資產增長的能量，打造極致的 Web3 行動體驗。核心機制與技術無感數據抓取：串接 Apple HealthKit 與 Google Fit，在背景自動讀取步數與睡眠數據，實現零門檻的「無感」Web3 體驗。動態全息 NFT 裝備：玩家的「虛擬跑鞋」為動態 NFT。隨著運動量累積與等級提升，跑鞋的霓虹光條與外觀會進化，解鎖更炫目的特效。硬體級防作弊：結合手機原生陀螺儀與 GPS 進行交叉驗證，杜絕「搖步機」等惡意刷榜行為，確保整體經濟生態的公平性。原生行動體驗：前端採用 React Native 搭配 Solana Mobile Wallet Adapter，實現流暢的錢包連線與毫秒級交易簽章。SKR 代幣經濟模型為了爭取 10,000 美元的 SKR 專屬創意獎項，NeonShift 設計了完整的代幣消耗（Sink）與產出機制：系統機制代幣流向應用場景說明日常任務打卡產出達成每日 8,000 步或 7 小時睡眠目標，系統自動空投基礎 SKR 獎勵。裝備進階升級消耗使用者需支付 SKR 來升級跑鞋 NFT 的「數據核心」，藉此提升未來的代幣產出倍率。賽季錦標賽對戰消耗 / 獎勵支付並質押 SKR 參與週末「步數馬拉松」，排名前段班的特工可瓜分高額獎金池。四週開發衝刺時程第一週（架構與 UI）：完成 React Native 基礎環境搭建，實作賽博龐克風介面（如霓虹數據面板），並完成手機健康 API 串接。第二週（區塊鏈整合）：導入 Mobile Wallet Adapter，撰寫並於測試網部署負責驗證與發放 SKR 的輕量級 Solana 智能合約。第三週（機制與測試）：實裝防作弊邏輯與 SKR 質押/消耗功能，並進行實機跑動測試，微調代幣發放參數。第四週（打磨與提交）：拍攝主打「手機硬體結合 Solana 生態」的 Demo 影片，準備 Pitch 文件，並於 10 月 8 日前完成 dApp Store 發布提交。
