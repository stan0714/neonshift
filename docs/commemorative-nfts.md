## 1. 首次距離：Genesis Distance 系列

| 成就 | 類別 ID | 單次有效跑步門檻 | 視覺概念 |
|---|---|---|---|
| 首次 5K · First Spark／初光 | first_5k | 5,000 m | 青綠起跑門、5 個光點 |
| 首次 10K · Double Horizon／雙境 | first_10k | 10,000 m | 冰藍雙層地平線、10K 字標 |
| 首次半馬 · Halfway to Infinity／半程無界 | first_half | 21,097.5 m | 紫色半環光帶、21.0975K 字標 |
| 首次全馬 · Marathon Genesis／全程起源 | first_marathon | 42,195 m | 紫綠完整環、終點拱門、42.195K 字標 |

### 判定規則

- 只取一個已完成且有效的 running session／主辦方結果，不累加多天、跨 session 或把步數換算估距當成正式里程。
- 完成狀態必須 FINISHED；DNS／DNF／DSQ 不授予該賽事距離首次完賽章。短於門檻不因 UI 四捨五入而通過：21.09 km 不等於半馬，42.19 km 不等於全馬。
- 主辦方正式距離與完賽結果為其賽事認證依據，不因手錶量到 42.0 km 就否定官方全馬；自行累積 42.195 km 只標為 Device recorded distance，不宣稱官方馬拉松完賽。
- 裝置來源須符合跑步專章的品質、完整性與去重規則；估算值、手動編輯及待審資料不取得鑄造資格。
- road／trail／treadmill 與 organizer／device 各自保存成就分類及來源，不混稱同一種認證。第一階段半馬／全馬只開放主辦方確認；裝置版待長距離品質規則及實機驗收後再啟用。
- 同一筆有效全馬可同時解鎖較短距離的首次「單次距離達標」：5K、10K、半馬、全馬，但都引用同一 session。不得稱為分別參加過四場賽事，也不推算最快 5K／10K。UI 顯示「本次解鎖 4 個里程碑」，玩家逐枚選擇領取；批次鑄造另作後續優化。
- 「首次」意指目前授權、已匯入並驗證的紀錄中最早一次，不保證是人生首次。確認頁顯示同步涵蓋範圍與來源；匯入更早資料只修正關聯歷史，不再次發同類成就。
- 比較依運動結束時間，時間相同按穩定 session ID 決定；主辦方資料以其確認完成時間為準，缺少可比時間則待審，不用匯入時間冒充首次時間。

## 2. 值得紀念的情境

| 系列／情境 | 可測條件（設計預設） | 次數限制 | 上線順序 |
|---|---|---|---|
| First Finish／首次完賽 | 首個主辦方已發布 FINISHED 活動結果 | 每玩家一次，活動型別分明 | 第一階段 |
| Event Memory／活動留念 | 該活動發布紀念章且參加者完成其公開條件；報到章與完賽章分開 | 每玩家／活動／章別一次 | 第一階段，沿用活動 NFT |
| Welcome Back／再次出發 | 兩筆有效跑步間隔至少 30 天；回歸跑至少 1 km；資料涵蓋完整才判定間隔 | 每玩家／UTC 年一次 | 第二階段 |
| First Anniversary／同行一週年 | 自 PlayerProfile 建立滿 365 天，且至少 12 個不同 UTC 週有成功任務 | 每玩家一次 | 第二階段 |
| Season Keeper／巔峰守護 | 以 Lv5 完成整個維持期，符合原鞋階維持規則 | 每玩家／維持期一次 | 沿用既有方案，不再新增相同章 |
| Personal Memory／我的紀念 | 玩家選一筆自己的紀錄，自填短標題並預覽內容 | 私人紀念卡；NFT 暫不開放 | 後續評估 |

Welcome Back 只能表示「已同步紀錄中的再次出發」，不推論使用者 30 天完全沒運動；資料權限不足不誤發。首階段健康摘要仍限 30 天，這類長期成就須先有使用者同意的最小歷史索引與相應保留政策，不得靠延長原始健康資料保存來支援。

不以減重、卡路里、傷後康復、熬夜跑、極端高溫、每日加量或連續無休作紀念條件。紀念重點是個人故事與參與，不把高風險挑戰或私人健康推論當成遊戲獎勵。

## 3. 與鞋階權限的關係

**首次距離與 First Finish 是基礎終身成就，Lv1 即可取得與領取**，補充鞋階矩陣中的基本里程碑。第一次完成 5K 時只有 Lv1，也不會失去紀念機會。

- 首次距離章：Lv1；官方與裝置來源仍各自驗證。
- 活動專屬紀念章：沿用 Lv2／報名時承諾權限，與基礎 First Finish 不同。
- 破 PB NFT：仍需達成時 Lv3；一筆首 5K 可獲基礎首次章，但不因此繞過 PB 權限。
- 複合挑戰／高階版式：Lv4；巔峰守護：Lv5。高階僅增加能力或樣式，不剝奪已獲基礎紀念。
- 正常降級不收回 NFT，也不取消已核准的鑄造資格。免費升級、不扣 XP、實際費用揭露等既有規則保留。

## 4. 鑄造與重複防護

首次成就唯一 key 為 `(wallet, category, environment, verification_class)`；不包含來源 revision、匯入批次、規則版本或年份，避免更正／重傳產生第二枚「首次」。活動章與年度章另使用 event ID／year，不能套用首次 key。

同一來源規則的小版本更新沿用 key；重大分類調整須有顯式 migration／類別對應，不重新命名來重發。achievement ID 由後端依穩定 key 分配並綁至 registry，鏈上 receipt 亦保證該 stable key 僅一次。

沿用新增 `claim_achievement`，不要把新類別 ID 直接塞入既有固定 kind 的 `claim_collectible`。簽章須綁定 wallet、穩定 key、資格 revision、來源類別、metadata hash 及有效期；使用者不能自行指定未授權圖片／成績。資格 registry 決定是否已撤銷，鑄造與 receipt 寫入原子完成。

來源被修正／刪除：未鑄造時重算最早有效來源，沿用穩定 key；已鑄造時保留鏈上作品，App 標示來源更正或 Invalidated。若後續重新達標，更新同 key 的有效性／來源紀錄，不再鑄第二枚；對外明示原作品快照與目前核驗狀態的差異。NFT 轉出後不重開領取資格，原達成者不變。

## 5. 藝廊與畫面

Gear／My collection 新增 Milestones；Profile／Running history 的摘要可同時顯示「First 5K」「First Finish」「New PB」等不同種類卡片。藝廊新增「首次」「活動」「PB」「長期紀念」篩選，不另外增加主 Tab。

每張卡片提供：章名、門檻、來源等級、環境、未解鎖／待審／可領取／待確認／已領取狀態。已擁有 NFT 保留完整彩色作品；尚未解鎖用輪廓與條件文字，不顯示假成績。第一階段採四枚一致構圖的向量／靜態作品，動效沿用 Reduce Motion 策略。

領取預覽逐項列出會公開的內容；預設只公開成就類別、門檻與必要鏈上識別。實際時間、精確距離、日期、活動名等另需主動同意。門檻本身也會透露運動成就，不能稱為完全匿名。不上傳原始 GPS／體重／心率／卡路里到 NFT。

紀念章只是經平台規則確認的紀錄，不暗示官方路跑認證、醫療健康證明或投資價值；主辦方 logo 與聯名造型必須取得使用授權。

## 6. 需求、測試與交付

第一階段：四距離／首次完賽規則 → 穩定 key 與 registry → 鑄造／收藏頁 → 四款作品。第二階段：長期歷史同意與回歸／週年情境。個人自訂紀念 NFT 及聯名系列另估，不默認開放。

必測：4,999.999／5,000 m、9,999.999／10,000 m、21,097.499／21,097.5 m、42,194.999／42,195 m；官方全馬與裝置短測；跨日 session、不累加多次跑步；長距離解鎖多章；首次／PB 權限不同；重複來源／更早回填／修正／失效後再達標；轉出 NFT 後重領；並發鑄造與拒簽；公開同意與資料刪除；回歸紀錄涵蓋不足不誤判。

本設計不修改現有代幣／XP／維持點計分，也不新增「跑越遠維持點越多」機制。
